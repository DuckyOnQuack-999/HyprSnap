# Changelog

All notable changes to HyprSnap will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of HyprSnap
- GIF recording functionality with area selection
- FFmpeg-based conversion pipeline with optimization
- Wayland compositor support (Hyprland, Sway, GNOME)
- Dunst notification integration
- Global hotkey support
- Basic configuration system
- Installation script with dependency management
- Support for multiple Linux distributions

### Features
- Region selection using slurp
- High-quality GIF recording with wf-recorder
- Configurable frame rates (15-60fps)
- Quality presets for different use cases
- File size optimization options
- Progress indicators and notifications
- Temporary file cleanup

### Technical
- Implemented robust error handling
- Added Wayland session detection
- Created comprehensive documentation
- Added shellcheck compliance
- Established version control structure
